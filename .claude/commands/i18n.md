## 工作流程

### 第一步：提取并更新翻译字符串

执行以下命令提取和更新翻译：

```bash
cd /Users/shiwenbin/Desktop/mcp-client && python scripts/i18n.py extract && python scripts/i18n.py update
```

### 第二步：查找未翻译的条目

读取英文翻译文件，找出所有 `msgstr ""` 的条目（即未翻译的条目）：

**文件路径**: `locales/en/LC_MESSAGES/messages.po`

找出所有形如以下格式的未翻译条目：

```
#: path/to/file.py:123
msgid "中文原文"
msgstr ""
```

### 第三步：翻译未翻译的条目

对于每个未翻译的条目，你需要：

1. 理解中文原文 (msgid) 的含义和语境
2. 提供准确、自然的英文翻译
3. 翻译风格要求：
   - **简洁明了**：避免冗余词汇
   - **语境匹配**：考虑这是用户界面文本、错误消息还是提示信息
   - **一致性**：类似的中文表达应翻译成一致的英文

### 第四步：更新翻译文件

使用 Edit 工具将翻译后的内容写入 `locales/en/LC_MESSAGES/messages.po` 文件。

对于每个未翻译的条目，将：

```
msgid "中文原文"
msgstr ""
```

替换为：

```
msgid "中文原文"
msgstr "English Translation"
```

### 第五步：编译翻译文件

完成翻译后，编译 PO 文件为 MO 文件：

```bash
cd /Users/shiwenbin/Desktop/mcp-client && python scripts/i18n.py compile
```
